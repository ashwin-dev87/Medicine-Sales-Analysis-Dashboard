---

## 📊 Dashboard Overview

The **Medicine Sales Analysis Dashboard** provides an end-to-end view of pharmaceutical sales operations, enabling data-driven decisions through rich, interactive visualizations.

### Key Highlights
- 📅 Multi-period analysis: **Daily | Weekly | Monthly | Yearly**
- 💰 Revenue trends and forecasting
- 🏷️ Product-wise sales performance
- 📈 Key business metrics at a glance
- 🔍 Interactive drill-through and filtering

## 🔍 Features

| Feature | Description |
|---|---|
| **Sales Performance** | Track overall revenue and units sold across time periods |
| **Product Analysis** | Compare medicine-wise sales volume and revenue contribution |
| **Revenue Trends** | Visualize growth patterns with line/bar charts |
| **Time Intelligence** | Dynamic filtering by day, week, month, and year |

## 🚀 Getting Started

### Prerequisites
- [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (latest version recommended)
- Microsoft Excel (for viewing/editing data sources)

### Steps to Run

1. **Clone the repository**
```bash
   git clone https://github.com/ashwin-dev87/Medicine-Sales-Analysis-Dashboard.git
```

2. **Open the dashboard**
   - Launch **Power BI Desktop**
   - Open `Medicine Sales Analysis.pbix`

3. **Refresh data (if needed)**
   - Go to **Home → Refresh**
   - Ensure all `.xlsx` files are in the same directory as the `.pbix` file

4. **Explore the dashboard**
   - Use slicers to filter by time period or product
   - Click on visuals to cross-filter across the report
